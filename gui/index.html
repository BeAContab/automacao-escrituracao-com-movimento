info Como obter sua chave de API (Google Gemini)

Para utilizar a IA do Gemini, você precisa de uma API Key gratuita da Google.

  1. Acesse Google AI Studio e faça login.
  2. Clique em "Get API key" e depois em "Create API key".
  3. Copie a chave gerada e cole no campo do Gemini abaixo.

info Como obter sua chave de API (Groq)

Para utilizar a IA da Groq como fallback ou extrator, você precisa de uma API Key.

  1. Acesse Groq Console e faça login.
  2. Clique em "Create API Key", forneça um nome e crie a chave.
  3. Copie a chave gerada e cole no campo do Groq abaixo.
