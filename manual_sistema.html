Visão Geral do Sistema

O BeAContab Automação é uma plataforma de robótica de processos contábeis (RPA) desenvolvida exclusivamente para o escritório Barreira & Associados. O sistema é composto por três módulos integrados que cobrem o ciclo completo de tratamento de notas fiscais de serviços (NFS-e) junto ao portal da Prefeitura de Fortaleza — ISS Fortaleza.

MóduloDescriçãoTecnologia
Processar XMLsLeitura e classificação de NFS-e com IAPython + Tess AI
Automação: EscrituraçãoDigitação automatizada no portal ISSPython + Selenium
Exportar XMLs PrestadosDownload em lote de NFS-e emitidasPython + Selenium
ℹ️
O sistema não realiza nenhuma ação no portal da Prefeitura sem a autenticação manual e prévia do operador responsável. O robô aguarda o login ser concluído antes de executar qualquer automação.

Requisitos e Instalação

Requisitos de Sistema

  • Sistema Operacional: Windows 10 ou superior (64 bits)
  • Navegador: Google Chrome instalado (versão atualizada)
  • Acesso à internet para comunicação com o portal ISS Fortaleza e a API do Tess AI
  • Credenciais de acesso válidas ao portal ISS Fortaleza
  • Chave de API e ID do Agente do Tess AI (para o módulo de Processamento de XML)

Instalação

  1. Execute o instalador BeAContab_Automacao_Setup.exe fornecido pelo administrador do sistema.
  2. Siga as etapas do assistente de instalação. O sistema será instalado em C:\Program Files\BeAContab por padrão.
  3. Após a instalação, localize o ícone BeAContab Automação na área de trabalho e execute-o.
  4. Na primeira execução, configure a Chave de API e o ID do Agente do Tess AI no painel lateral esquerdo (veja a Seção 3).
⚠️
Atenção: O Google Chrome deve estar instalado na máquina. A automação de navegador não é compatível com outros navegadores como Firefox, Edge ou Opera.
3

Configuração do Tess AI

O Tess AI é a plataforma de inteligência artificial utilizada para classificar os códigos CNAE das notas fiscais de forma automática durante o Processamento de XMLs.

  1. Acesse o painel do Tess AI em tess.pareto.io e faça login com a conta do escritório.
  2. Gere uma Chave de API nas configurações da sua conta e copie-a.
  3. Localize o ID do Agente de Classificação de CNAE criado pelo administrador.
  4. No sistema BeAContab, informe a Chave de API e o ID do Agente nos campos na parte inferior da barra lateral esquerda.
  5. Clique em Salvar Configuração. As credenciais são armazenadas localmente de forma segura.
✅
As credenciais do Tess AI são armazenadas de forma persistente no computador do usuário. Elas não são perdidas ao fechar o programa.

Função 1 — Processamento de XMLs

O que faz?

Lê uma pasta de arquivos XML de NFS-e, extrai as informações fiscais relevantes de cada nota e utiliza o agente de inteligência artificial do Tess AI para classificar automaticamente o código CNAE. Ao final, gera uma planilha Excel consolidada com todos os dados estruturados, pronta para ser utilizada na escrituração.

Pré-requisitos

  • Pasta com os arquivos XML das NFS-e (exportados do portal ISS Fortaleza).
  • Arquivo cnae_oficial.xlsx presente no diretório de instalação do sistema (já incluído).
  • Chave de API e ID do Agente do Tess AI configurados (ver Seção 3).

Passo a Passo de Operação

  1. Clique na aba Processar XMLs na barra lateral esquerda.
  2. Clique em Pasta e selecione a pasta onde estão os arquivos .xml.
  3. Verifique se a Chave de API e o ID do Agente do Tess AI estão preenchidos no painel lateral.
  4. Clique em INICIAR PROCESSAMENTO DE XMLs.
  5. Acompanhe o progresso e os logs na tela.
  6. Ao finalizar, o caminho da planilha gerada será exibido no console de log.
ℹ️
Cache Local de CNAE: Para otimizar o uso de tokens da API, o sistema armazena em cache os CNAEs já classificados. Se o mesmo código de serviço aparecer em múltiplas notas, a classificação é reutilizada sem novas chamadas à IA.

Função 2 — Automação de Escrituração

O que faz?

Automatiza a digitação dos dados de notas fiscais no portal ISS Fortaleza, substituindo o processo manual e repetitivo. O robô lê a planilha Excel gerada no módulo anterior e, após o login manual do operador, realiza os lançamentos de forma sequencial e precisa.

Pré-requisitos

  • Planilha Excel previamente gerada pelo módulo de Processamento de XMLs.
  • Credenciais de acesso válidas ao portal ISS Fortaleza.
  • Conexão estável com a internet durante toda a execução.

Passo a Passo de Operação

  1. Clique na aba Automação: Escrituração na barra lateral esquerda.
  2. Clique em Selecionar e escolha o arquivo .xlsx gerado no processamento.
  3. Selecione o Mês e o Ano de Competência nos campos de seleção.
  4. Clique em Iniciar Automação. O Chrome será aberto no portal ISS Fortaleza.
  5. Quando o card "Aguardando Login Manual" aparecer, faça login no portal e clique em Confirmar Login Realizado.
  6. O robô assumirá o controle e iniciará a escrituração nota a nota. Acompanhe o progresso no console.
⚠️
Importante: Não interaja com o navegador aberto pelo robô durante a automação. Qualquer clique ou digitação manual pode interromper o fluxo e causar erros.
ℹ️
Pausar e Retomar: Caso precise interromper momentaneamente a automação, utilize o botão PARAR AUTOMAÇÃO que aparece no console durante a execução. Clique novamente para retomar.

Função 3 — Exportar XML de Serviços Prestados

O que faz?

Automatiza o download em lote dos arquivos XML de NFS-e (Serviços Prestados) diretamente do portal ISS Fortaleza. O robô filtra as notas pela competência escolhida e realiza a exportação em lotes de até 10 páginas por vez.

Pré-requisitos

  • Credenciais de acesso válidas ao portal ISS Fortaleza.
  • Uma pasta de destino com permissão de escrita para receber os arquivos XML baixados.
  • Conexão estável com a internet durante toda a execução.

Passo a Passo de Operação

  1. Clique na aba Exportar XML de Prestados na barra lateral esquerda.
  2. Clique em Selecionar e escolha a pasta onde os XMLs serão salvos.
  3. Selecione o Mês e o Ano de Competência desejados.
  4. Clique em Iniciar Exportação. O Chrome será aberto no portal ISS Fortaleza.
  5. Quando o card "Aguardando Login Manual" aparecer, faça login no portal e clique em Confirmar Login Realizado.
  6. O robô acessará "Consultar NFS-e", filtrará pela competência e iniciará o processo de seleção e exportação em lote.
  7. Cada lote de até 10 páginas será exportado como um arquivo ZIP separado, salvo na pasta de destino.
  8. A mensagem "Exportação concluída!" será exibida ao término do processamento.
ℹ️
Lotes de 10 páginas: O portal ISS Fortaleza impõe limites de seleção por vez. O sistema divide automaticamente a exportação em grupos de até 10 páginas, garantindo que todos os registros sejam exportados sem perda de dados.
✅
O navegador permanece aberto ao final da exportação, permitindo que o operador realize outras consultas manualmente.

Solução de Problemas

ProblemaCausa ProvávelSolução
Erro ao abrir o ChromeGoogle Chrome não instalado ou desatualizadoInstale ou atualize o Google Chrome para a versão estável mais recente.
Timeout ao aguardar elementoLentidão na conexão ou no carregamento do portalVerifique a conexão com a internet e tente novamente em horário de menor tráfego.
Login expirado durante automaçãoSessão do portal encerrada por inatividadeReinicie a automação. Não deixe o computador entrar em modo de espera durante o processamento.
Planilha não encontradaCaminho do arquivo Excel inválido ou arquivo movidoUse o botão "Selecionar" para escolher novamente o arquivo correto.
Erro de API do Tess AIChave de API inválida, expirada ou sem saldoRenove a Chave de API no painel do Tess AI (tess.pareto.io) e atualize a configuração.
XMLs não são baixadosPermissão de escrita negada na pasta de destinoEscolha uma pasta com permissão de gravação, como Documentos ou Downloads.
Automação salta etapasResolução de tela diferente ou layout do portal alteradoContate o administrador do sistema para atualização dos seletores do robô.

Onde encontrar os Logs de Execução

O sistema mantém um histórico de execuções em:

C:\Users\[USUÁRIO]\AppData\Roaming\BeAContab\logs\

Em caso de erros inesperados, envie o arquivo de log mais recente ao administrador do sistema para análise e suporte técnico.
