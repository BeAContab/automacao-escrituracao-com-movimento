Visão Geral do Sistema

O Automações ISS é a plataforma de robótica de processos contábeis (RPA) desenvolvida exclusivamente para o escritório Barreira & Associados. O sistema reúne 5 automações integradas em um único programa, cobrindo o ciclo completo de tratamento de notas fiscais de serviços (NFS-e) junto ao portal da Prefeitura de Fortaleza — ISS Fortaleza.

FunçãoDescriçãoSituação
1. Processar XMLsLeitura e classificação de NFS-e com IAEstável
2. Automação: EscrituraçãoDigitação automatizada no portal ISSEm testes
3. Exportar XML de PrestadosDownload em lote de NFS-e emitidasEstável
4. Captura Escrituração (Com Movimento)Baixa certificados de escrituração de empresas encerradas com movimentoEm testes
5. Encerramento ISS (Sem Movimento)Encerra a escrituração de empresas sem movimento/inativasEm testes
🧪
Sobre o selo "Em Testes": as funções marcadas acima ainda estão em fase de validação em produção. Elas já funcionam ponta a ponta, mas recomenda-se conferir manualmente os resultados (certificados, planilhas e relatórios gerados) até que a equipe técnica remova o selo na interface.
ℹ️
Nenhuma das 5 funções realiza qualquer ação no portal da Prefeitura sem a autenticação manual e prévia do operador (login com CPF/senha, ou confirmação manual de login). O robô sempre aguarda essa etapa antes de agir.

Requisitos e Instalação

Requisitos de Sistema

  • Sistema Operacional: Windows 10 ou superior (64 bits)
  • Navegador: Google Chrome instalado (versão atualizada)
  • Acesso à internet para comunicação com o portal ISS Fortaleza e a API do Tess AI
  • Credenciais de acesso válidas ao portal ISS Fortaleza (CPF e senha)
  • Chave de API e ID do Agente do Tess AI (para a Função 1 — Processar XMLs)

Instalação

  1. Execute o instalador Setup_Automacoes_ISS_v2.26.0.exe fornecido pelo administrador do sistema.
  2. Siga as etapas do assistente de instalação. O sistema será instalado em C:\Program Files\Automações ISS por padrão.
  3. Após a instalação, localize o atalho Automações ISS na área de trabalho ou no Menu Iniciar e execute-o.
  4. Na primeira execução, configure a Chave de API e o ID do Agente do Tess AI no painel lateral esquerdo (veja a Seção 4).
⚠️
Atenção: O Google Chrome deve estar instalado na máquina. As automações de navegador não são compatíveis com outros navegadores como Firefox, Edge ou Opera.

Conhecendo a Interface

Ao abrir o programa, você encontra três áreas principais, sempre visíveis:

  • Menu lateral (esquerda): lista as 5 funções do sistema, cada uma com um ícone. A função ativa aparece destacada em laranja. No rodapé do menu fica o painel de configuração do Tess AI.
  • Cabeçalho (topo): mostra o nome da função aberta no momento, e um botão para fechar o programa.
  • Área central: onde ficam os parâmetros de cada função (à esquerda) e o console de acompanhamento em tempo real, com barra de progresso e log de execução (à direita).
✅
Todas as funções seguem o mesmo padrão visual: preencha os campos do card à esquerda, clique no botão de ação (laranja) e acompanhe o andamento no console à direita. Isso é válido para as 5 funções do sistema.

Configuração do Tess AI

O Tess AI é a plataforma de inteligência artificial utilizada para classificar os códigos CNAE das notas fiscais de forma automática durante o Processamento de XMLs (Função 1).

  1. Acesse o painel do Tess AI em tess.pareto.io e faça login com a conta do escritório.
  2. Gere uma Chave de API nas configurações da sua conta e copie-a.
  3. Localize o ID do Agente de Classificação de CNAE criado pelo administrador.
  4. No sistema, informe a Chave de API e o ID do Agente no painel "Configuração Tess AI", na parte inferior da barra lateral esquerda.
  5. Clique em Salvar Configuração. As credenciais são armazenadas localmente de forma segura.
✅
As credenciais do Tess AI ficam salvas de forma persistente no computador do usuário. Elas não são perdidas ao fechar o programa.

Função 1 — Processar XMLs

O que faz?

Lê uma pasta de arquivos XML de NFS-e, extrai as informações fiscais relevantes de cada nota e utiliza o agente de inteligência artificial do Tess AI para classificar automaticamente o código CNAE. Ao final, gera uma planilha Excel consolidada com todos os dados estruturados, pronta para ser utilizada na Função 2 (Automação: Escrituração).

Pré-requisitos

  • Pasta com os arquivos XML das NFS-e (layout Portal Nacional ou Portal Da Paraíba — detectado automaticamente).
  • Chave de API e ID do Agente do Tess AI configurados (ver Seção 4).

Passo a Passo de Operação

  1. Clique na aba Processar XMLs na barra lateral esquerda.
  2. Clique na área "Pasta de Origem dos XMLs" e selecione a pasta onde estão os arquivos .xml.
  3. Verifique se a Chave de API e o ID do Agente do Tess AI estão preenchidos no painel lateral.
  4. Clique em Iniciar Processamento.
  5. Acompanhe o progresso e o log de execução na tela, à direita.
  6. Ao finalizar, use o botão Abrir Planilha Gerada (ou Abrir Pasta com as Planilhas Geradas, se houver mais de uma subpasta) para acessar o resultado.
ℹ️
Cache local de CNAE: para economizar chamadas à IA, o sistema reaproveita a classificação de CNAEs já processados para o mesmo código de serviço, sem gastar tokens novamente.

Função 2 — Automação: Escrituração 🧪 Em Testes

O que faz?

Automatiza a digitação dos dados de notas fiscais no portal ISS Fortaleza. O robô lê a planilha Excel gerada na Função 1 e, após o login manual do operador, realiza os lançamentos nota por nota, de forma sequencial.

Campos do formulário

  • Planilha Excel Origemarquivo .xlsx gerado na Função 1 (Processar XMLs)
  • Mês / Ano Competênciacompetência fiscal a ser escriturada

Passo a Passo de Operação

  1. Clique na aba Automação: Escrituração.
  2. Clique em Selecionar e escolha o arquivo .xlsx gerado no processamento.
  3. Selecione o Mês e o Ano de Competência.
  4. Clique em Iniciar Escrituração. O Chrome será aberto no portal ISS Fortaleza.
  5. Quando o aviso "Aguardando Login Manual" aparecer, faça login no portal e clique em Confirmar Login Realizado.
  6. O robô assume o controle e inicia a escrituração nota a nota. Acompanhe pela barra de progresso e pelo log.
⚠️
Importante: não interaja com o navegador aberto pelo robô durante a automação. Qualquer clique ou digitação manual pode interromper o fluxo e causar erros.
ℹ️
Pausar, retomar e cancelar: use os botões que aparecem no console durante a execução para pausar/retomar a qualquer momento, ou cancelar por completo (o navegador é fechado e será preciso reiniciar do zero).

Função 3 — Exportar XML de Prestados

O que faz?

Automatiza o download em lote dos arquivos XML de NFS-e (Serviços Prestados) diretamente do portal ISS Fortaleza. O robô filtra as notas pela competência escolhida e realiza a exportação, reunindo os resultados em arquivos XML combinados.

Campos do formulário

  • Pasta de Destinopasta onde os arquivos XML baixados serão salvos
  • Mês / Ano Competênciacompetência fiscal a ser consultada e exportada

Passo a Passo de Operação

  1. Clique na aba Exportar XML de Prestados.
  2. Clique em Selecionar e escolha a pasta onde os XMLs serão salvos.
  3. Selecione o Mês e o Ano de Competência desejados.
  4. Clique em Iniciar Exportação. O Chrome será aberto no portal ISS Fortaleza.
  5. Quando o aviso "Aguardando Login Manual" aparecer, faça login no portal e clique em Confirmar Login Realizado.
  6. O robô acessa "Consultar NFS-e", filtra pela competência e seleciona todas as notas de cada página, exportando-as em arquivos XML combinados a cada 10 páginas.
  7. A mensagem "Tudo pronto!" é exibida ao término, com o total de arquivos XML gerados.
ℹ️
Um arquivo pode conter várias notas: cada arquivo XML exportado reúne as notas de até 10 páginas de resultado — não é "1 arquivo = 1 nota". O log final informa quantos arquivos foram gerados, não quantas notas individuais.
✅
O navegador permanece aberto ao final da exportação, permitindo que o operador realize outras consultas manualmente.

Função 4 — Captura Escrituração (Com Movimento) 🧪 Em Testes

O que faz?

Baixa automaticamente os certificados de escrituração ISS das empresas que foram encerradas com movimento em uma data específica. O robô lê a planilha fiscal, filtra as empresas de Fortaleza encerradas na data informada (e que não estejam marcadas como "sem movimento"), procura a inscrição de cada uma no portal e baixa o certificado de escrituração da competência escolhida.

Campos do formulário

  • Planilha Fiscalplanilha .xlsx com a aba nomeada MM.AAAA da competência
  • Pasta de Saídaonde os certificados baixados serão organizados por ano/mês
  • Mês / Ano Competênciacompetência da escrituração a ser baixada
  • Data de Encerramentofiltra só as empresas encerradas nessa data exata
  • CPF / Senhacredenciais de acesso ao portal ISS Fortaleza
  • Configurações Avançadascaminho do Chrome e URL do portal — já vêm preenchidos, só altere se necessário

Passo a Passo de Operação

  1. Clique na aba Captura Escrituração.
  2. Selecione a Planilha Fiscal e a Pasta de Saída.
  3. Escolha o Mês/Ano de Competência e a Data de Encerramento a filtrar.
  4. Informe CPF e Senha do portal ISS Fortaleza.
  5. Clique em Iniciar Captura. O robô faz login automaticamente e começa a processar a planilha, empresa por empresa.
  6. Acompanhe pelo log de execução; use Cancelar se precisar interromper.
ℹ️
Diferente das Funções 2 e 3, esta função faz o login automaticamente com o CPF/senha informados — não é necessário confirmar login manual, a menos que o portal peça uma verificação extra.

Função 5 — Encerramento ISS (Sem Movimento) 🧪 Em Testes

O que faz?

Encerra automaticamente a escrituração ISS das empresas marcadas como sem movimento ou inativas na planilha fiscal (responsável começando com "SM -", "SEM MOVIMENTO -" ou "INATIVA -"). Para cada empresa, o robô verifica se há serviços prestados ou pendentes — se houver, marca como problema e segue adiante; se não houver, encerra a escrituração, baixa o certificado em PDF e grava a data de encerramento de volta na planilha.

Campos do formulário

  • Planilha Fiscalmesma planilha fiscal usada nas demais funções
  • Pasta de Saídaonde ficam os certificados PDF e o relatório de execução
  • Mês / Ano Competênciacompetência a ser encerrada
  • CPF / Senhacredenciais de acesso ao portal ISS Fortaleza
  • Configurações Avançadascaminho do Chrome e URL do portal

Passo a Passo de Operação

  1. Clique na aba Encerramento ISS.
  2. Selecione a Planilha Fiscal e a Pasta de Saída.
  3. Escolha o Mês/Ano de Competência.
  4. Informe CPF e Senha do portal ISS Fortaleza.
  5. Clique em Realizar Encerramento.
  6. Ao final, confira o card Resumo da Execução — mostra quantas empresas foram Processadas, quantas foram Encerradas e quantas tiveram Problemas.
  7. Clique em Abrir Relatório de Execução para ver o detalhamento completo em Excel.
⚠️
Esta função altera dados no portal da Prefeitura: o encerramento da escrituração não é uma consulta — é uma ação real e, na prática, difícil de reverter. Confira com atenção a lista de empresas na planilha antes de iniciar.

Onde Ficam os Logs de Cada Execução

Toda vez que uma automação é executada, o sistema grava automaticamente um arquivo de log dentro de uma subpasta log, criada na pasta de saída que você informou para aquela função — assim o histórico de cada execução fica junto do resultado gerado, e não espalhado em outro lugar.

FunçãoOnde o log é salvo
Processar XMLs[pasta de origem selecionada]\log\
Automação: Escrituração[pasta da planilha selecionada]\log\
Exportar XML de Prestados[pasta de destino selecionada]\log\
Captura Escrituração[pasta de saída selecionada]\log\
Encerramento ISS[pasta de saída selecionada]\log\

Cada arquivo é nomeado log_execucao_AAAAMMDD_HHMMSS.txt e contém a mesma narrativa exibida no console da tela, com horário de cada etapa — útil para conferir depois o que aconteceu numa execução, ou para enviar ao suporte técnico em caso de erro.

ℹ️
As credenciais do Tess AI (Seção 4) são a exceção: ficam salvas separadamente em %APPDATA%\BeAContab\.env, não junto dos logs de execução.

Solução de Problemas

ProblemaCausa ProvávelSolução
Erro ao abrir o ChromeGoogle Chrome não instalado ou desatualizadoInstale ou atualize o Google Chrome para a versão estável mais recente.
Automação trava sem mensagem de erroUm elemento do portal não foi encontrado (o portal pode ter mudado o layout)Aguarde o tempo limite (até 60s) para o erro aparecer no log; se persistir, contate o administrador do sistema.
Login expirado durante automaçãoSessão do portal encerrada por inatividadeReinicie a automação. Não deixe o computador entrar em modo de espera durante o processamento.
Planilha não encontradaCaminho do arquivo Excel inválido ou arquivo movidoUse o botão "Selecionar" para escolher novamente o arquivo correto.
Erro de API do Tess AIChave de API inválida, expirada ou sem saldoRenove a Chave de API no painel do Tess AI (tess.pareto.io) e atualize a configuração.
Arquivos não são baixadosPermissão de escrita negada na pasta de destinoEscolha uma pasta com permissão de gravação, como Documentos ou Downloads.
Empresa aparece como "problema" no Encerramento ISSEmpresa tem serviços prestados ou pendentes no períodoComportamento esperado — o robô não encerra empresas com movimento real. Confira o relatório de execução para o motivo exato.
⚠️
Suporte Técnico: este sistema é de uso exclusivo do escritório Barreira & Associados. Em caso de dúvidas ou falhas, envie o arquivo de log mais recente (ver Seção 10) ao responsável técnico pela plataforma.
